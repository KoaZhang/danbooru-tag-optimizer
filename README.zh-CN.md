# Danbooru Tag Optimizer

一个 Claude Code 技能，用于生成、优化和维护 ComfyUI / Stable Diffusion 角色生图所需的 Danbooru 风格提示词。

## 功能

- **角色创建** — 根据角色描述生成覆盖全部 7 大分类的精确 Danbooru 标签
- **标签优化** — 替换泛化标签、补充缺失类别、增强辨识度
- **角色一致性** — 区分锚点标签（定义角色身份）和可变标签（随场景变化），含负向提示词建议
- **属性替换** — 在保持角色特征不变的前提下替换表情、服饰、场景

## 安装

### 作为 Claude Code 技能使用
下载 [danbooru-tag-optimizer.skill](https://github.com/KoaZhang/danbooru-tag-optimizer/releases/latest)，拖入 Claude Code 即可安装。

### 从源码安装
将本目录复制到 `~/.claude/skills/danbooru-tag-optimizer/`。

## 使用

安装后，当你谈论动漫角色标签时技能会自动激活。也可以在 Claude Code 中显式调用：

```
/danbooru-tag-optimizer
```

### 使用示例

**从设定创建角色：**
> 帮我创建一个原创角色：她是16岁的猫耳少女，粉色双马尾，绿色眼睛，身材娇小，性格元气活泼，穿哥特洛丽塔风格的衣服

**优化模糊的标签：**
> 这些 danbooru tags 太普通了：1girl, black hair, brown eyes, t-shirt, jeans, standing。帮我加点辨识度

**构建一致性方案：**
> 我想给我的 OC 生成不同场景的 prompt：日常、战斗、雨天、夜晚。角色是银发紫瞳的高挑精灵女剑士，需要确保每个场景都是同一个人

**替换属性保持一致性：**
> 把她的表情从生气改成微笑，衣服从战斗服换成和服，但角色本身的特征要保持不变

**排查角色漂移问题：**
> comfyui 画二次元角色总是画着画着就变样了，换了个姿势头发颜色都变了。有没有办法通过控制 tag 来保持角色稳定？

## 数据集

包含约 35,000 个分类的 Danbooru 标签，来源为 [Danbooru2024](https://huggingface.co/datasets/Wenaka/danbooru2024_general_tags_classified)，按 7 大类组织：

| 类别 | 标签数 | 子分类 |
|------|--------|--------|
| 人物本身的特征 | 2,429 | 14 个子类：头发/发型、眼睛/瞳孔、体型/身材、皮肤/体表、种族/兽化特征、脸部/头部特征、纹身/疤痕... |
| 表情 | 581 | — |
| 服饰 | 8,966 | 13 个子类：上装、下装、套装/制服、内衣/泳装、头饰/发饰、鞋子、袜子、颈饰、手饰、耳饰... |
| 动作 | 4,222 | — |
| 环境/背景 | 2,398 | — |
| 物品 | 10,232 | — |
| 构图 | 614 | — |

## 角色一致性的核心思路

技能将角色标签分为两类：

- **锚点标签**（必须保留）：发色发型、瞳色、体型、疤痕、种族特征 —— 这些定义了「这个角色是谁」
- **可变标签**（可自由替换）：表情、动作、服饰、场景、构图 —— 这些描述的是「这个角色在做什么」

通过固定锚点、灵活替换变量，在不同场景下保持角色视觉一致性。
